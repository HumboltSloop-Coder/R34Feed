# Contributing

Gracias por interesarte en contribuir.

## Reglas básicas

- Un pull request = un solo cambio coherente.
- No mezclar features con refactorings grandes.
- Sigue el estilo de código existente (Kotlin + Compose + Hilt).

## Pull Request

1. Crea una rama desde `main`.
2. Describe claramente qué cambia y por qué.
3. Asegúrate de que compile (`./gradlew assembleDebug`).
